# Thin foliage revision v4

Candidate asset for NeckGuardian environment review; not integrated into APK.

- `natural-tree-thin-foliage-v4.glb`: self-contained revised model, 30,490triangles, three mesh/material owners, 1,840thin curved leaves.
- `trunk-only.glb`: intermediate extracted branch check.
- `leaf-texture.png`: built-in imagegen natural elliptical leaf texture, alpha retained unchanged.
- `rebuild-report.json`, `model-audit.json`, `reproducibility.json`, `visual-review.json`: numeric and visual evidence.

Source Tripo GLB remains unchanged. Original retained triangle attributes and bark image bytes remain unchanged in the revision; thick green triangles are excluded by new index selection. New twig and foliage objects are authored locally; this asset must not be described as entirely generated by Tripo or packaged in Spatial Editor. Editor backend remained unavailable.

Rebuild on this macOS host: `python3 production/tools/rebuild-thin-foliage.py` from repository root. Uses Python standard library and macOS `sips` to decode the original atlas for hue segmentation. The script recreates temporary analysis files under `.scratch/foliage-rebuild/`.

Preview: `http://127.0.0.1:8781/production/preview/thin-foliage-v4.html` while the project HTTP server runs. Inspect front, back, trunk and crown. No additional paid Tripo generation; head-mounted sharpness and performance remain unverified. User visual acceptance is pending.
