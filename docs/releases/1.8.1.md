# 颈椎卫士 1.8.1 · 三维训练环境体验版

- 版本号：**1.8.1**
- versionCode：**10**
- 包名：`com.example.neckguardian`
- 类型：Debug 体验版（Pre-release）

## 更新内容

1. 舒颈飞行新增训练前环境选择：真实空间、林间晨光、湖畔薄雾、暖阳书房，并记住环境和环境音偏好。
2. 三个虚拟环境均使用实际三维模型。林间包含树林、起伏地形、步道与蕨类；湖畔包含木平台、湖面与岸线；书房包含书架、写字桌、阅读沙发与落地窗。
3. 重做树叶显示方案：从原叶片贴图提取轮廓，生成几何薄片，替代依赖透明裁切的矩形卡片。此调整旨在解决头显中叶片缺失的问题，实际显示仍待完整复核。
4. 湖畔与林间草地改为弯曲、渐细、高低错落的草簇，减少原先直三角片的生硬感。
5. 增加可选环境音；语音讲解时自动降低环境音，讲解结束后恢复；离开训练或切到后台时停止播放。
6. 场景按坐姿眼点与真实头姿校准，保持世界固定；提供重新定位。保留原飞机半尺寸、星星收集/错过/完成率、原高塔动画、双语专业男声及本地历史记录。

## 使用与验证范围

菜单、设置与历史保留原生窗口。真实空间使用透视训练，虚拟环境使用 Full Space；训练时其他应用进入后台，不提供跨应用后台姿态监测。

本地构建及28项单元测试通过；三套GLB校验均为0错误、0警告，APK内模型与确认预览的校验值一致。源码API、UI风格、位置检查及项目Accessibility静态检查通过。已覆盖安装PICO真机，日志确认新版林间、书房模型加载及真实头姿接收。

**尚未完成的验收：** 湖畔新叶片/草地的实机视觉复核、三场景佩戴舒适度及持续性能测试。Stage Accessibility运行检查恰逢用户切换页面，尚未形成稳定通过的证据。浏览器照明、水波和阴影不保证与原生画面一致；选择页缩略图仍是早期候选图。此前独立的PICO测试闪退反馈不在本版中宣称已修复。

本应用仅作健康参考，不构成医疗诊断或治疗建议。出现不适请停止练习，必要时就医。
