# 颈椎卫士 1.7 · 视觉升级体验版

- **版本号：** 1.7
- **versionCode：** 8
- **包名：** com.example.neckguardian
- **类型：** Debug 体验版

## 版本说明

1. 训练界面改为顶部数据区、透明模型区和底部操作区，突出高塔、飞机及角度仪表。
2. 高塔与纸飞机增加细腻纹理，保留原始模型结构、积木倾倒动画及飞机半尺寸碰撞规则。
3. 高塔新增随摆放位置移动的稳定环，角度超限时显示暖橙色反馈。
4. 舒颈飞行新增轻柔航迹与收集星星“+1”反馈，收集、错过及完成率规则保持一致。
5. 优化训练设置页与结果页，新增完成环、暖色面板和温和鼓励文案。
6. 保留中英文界面、专业男声引导及最近30条本地记录。
